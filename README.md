# TwitchTTS — озвучка Twitch-чата и голосовой опрос

Локальное приложение для стримов: читает чат Twitch **без логина и пароля** (анонимно),
озвучивает сообщения клонированными голосами и проводит голосовой опрос с озвучкой.
Всё считается на своей видеокарте, никуда наружу ничего не отправляется, кроме чата Twitch.

В репозитории — только код и документация. Модели, голоса и окружение весят около 35 ГБ
и скачиваются/создаются на месте (см. «Что не хранится в репозитории»).

---

## Возможности

* **Озвучка чата.** Любой может написать в чат — сообщение прозвучит голосом.
  Настраиваются: громкость, скорость, длина очереди, пауза между репликами одного
  зрителя, «только подписчики», стоп-лист слов, игнор ботов.
* **Два движка синтеза.**
  * **XTTS v2** — быстрый (1–2 секунды на фразу), переносит тембр.
  * **CosyVoice 3** — медленнее (6–9 секунд), но повторяет **интонацию исходной записи**:
    тембр и мелодия измеряются заметно ближе к оригиналу (замеры ниже).
    Переключатель — прямо в карточке голоса.
* **Свои голоса из записей.** Загружаете mp3/wav/видео с речью — программа сама
  нарезает её на фразы, выравнивает громкость, снимает слепок голоса и меряет высоту тона.
* **Подстройка тона.** У каждого голоса есть эталон высоты тона (измеренный по записи)
  и ручной сдвиг в полутонах, чтобы голос звучал на той же высоте, что персонаж.
* **Своя громкость голоса.** У каждого голоса есть свой ползунок 0–200 %: один голос
  можно сделать тише другого. Общая громкость тоже регулируется в пределах 0–200 %.
* **Мьют озвучки.** Кнопка «Озвучка» в шапке на всех страницах мгновенно выключает
  озвучку чата: текущая реплика и очередь замолкают, реплики продолжают приходить,
  но не читаются.
* **Чтение на любом языке.** Голос сам определяет язык сообщения и читает его
  правильным голосом: XTTS v2 тянет 17 языков (русский, английский, немецкий, французский,
  испанский, итальянский, португальский, польский, чешский, турецкий, арабский, китайский,
  японский, корейский, хинди, венгерский, украинский — через русский).
* **Эмоции в сообщениях.** Ремарка (смех), *вздыхает*, [кашель] звучит
  настоящей эмоцией, а не читается словом. Голоса CosyVoice 3 смеются и вздыхают сами,
  тембром персонажа; для XTTS и RVC используются записи из папки `sounds/`.
* **Голоса персонажей (RVC).** Обучаемые модели: программа умеет обучать RVC прямо
  из приложения по вашим записям (нарезка → признаки → обучение → индекс).
* **Опрос с озвучкой.** Вкладка «Опрос»: варианты, таймер, голоса зрителей.
  Объявления опроса тоже озвучиваются. Номера вариантов вслух не читаются,
  сообщения из одних цифр пропускаются — иначе получился бы кашу.
* **Оверлей для OBS.** Источник «Браузер» с адресом `/overlay` показывает сообщения чата
  поверх картинки стрима.
* **Twitch-чат читается анонимно** — логин и пароль не нужны.

## Интерфейс

Ровно две верхние вкладки:

```
Опрос | Голоса
```

* **Опрос** — под-вкладки **Голосование** (сам опрос), **Чат** (радар зала, подключение,
  очередь, выбор голоса по умолчанию) и **Озвучка** (что читать в объявлениях опроса,
  голос, громкость, проверка звука).
* **Голоса** — создание своих голосов, переключатель движка XTTS / CosyVoice 3,
  карточка CosyVoice 3 (статус, путь к модели, подключение, транскрипт образца),
  обучение RVC-моделей из записей, список всех голосов.

## Требования

| Что | Нужно |
|---|---|
| ОС | Windows 10 / 11 (x64) |
| Видеокарта | NVIDIA, 6–8 ГБ VRAM (проверено на RTX 5070) |
| Python | ставится автоматически скриптом `install.bat` |
| Место | ~6 ГБ (окружение) + 1,8 ГБ (модель XTTS) + 9 ГБ (CosyVoice 3) + 25 ГБ (Applio, по желанию) |

> **Важно: путь к программе и к модели CosyVoice должен быть без кириллицы.**
> Внутри CosyVoice используются бинарные FST-словари (kaldifst), и они не умеют
> открывать файлы по пути с русскими буквами — синтез падает с
> `Error opening input stream .../wetext/fsts/ru/tn/tagger.fst`.
> Латиница в путях работает: `B:\projects\TwitchTTS` — правильно.

## Установка и запуск

```
1. Запустить install.bat      # окружение Python + библиотеки, ~6 ГБ
2. Запустить start.bat        # сама программа
3. Открыть http://127.0.0.1:8765
4. Вкладка "Голоса" -> вписать канал -> "Подключить"
5. Нажать "Включить звук" на странице
```

Вкладку браузера держите открытой — звук идёт из неё. Чёрное окно не закрывайте:
это сама программа.

**Дополнительно (по желанию):**

* **CosyVoice 3** — второй движок. Нужна отдельная папка с моделью (~9 ГБ) и своим
  окружением Python. Программа ищет её сама; если не нашла — впишите путь в карточке
  «CosyVoice 3» и нажмите «Подключить». Модель грузится лениво: пока CosyVoice
  не используется, видеокарта остаётся свободной.
* **Applio (RVC)** — `get_applio.bat` скачивает и распаковывает движок (6,8 ГБ).
  Либо можно обучать RVC-модели прямо из приложения, если Applio установлен.

## Как добавить свой голос

1. Вкладка «Голоса» → «Добавить голос по записям (клонирование)».
2. Вписать имя и хотя бы одно другое имя/псевдоним — по нему голос выбирают в чате.
3. Перетащить записи (20–60 секунд чистой речи одного персонажа, минимум 6–10 секунд).
4. «Создать голос».

Программа сама нарежет запись на фразы, выровняет громкость, снимет слепок голоса
и посчитает эталон высоты тона. Подходят mp3, wav, ogg, flac, m4a, mp4, mkv, webm.

Музыку и шум программа не убирает — качество слепка зависит от чистоты записи.

## Команды в чате

| Команда | Что делает |
|---|---|
| `!г имя` | зритель выбирает себе голос (можно часть имени: «!г гер» найдёт «Геральт»). Старые `!голос` и `!voice` работают как алиасы. |
| `!скип` (`!skip`) | модератор или стример пропускает текущее сообщение. |

## Два движка: XTTS v2 и CosyVoice 3

Замеры на одной и той же записи (голос «Ренат», образец 10 секунд) — тембр сравнивался
по схожести голоса, мелодия — по корреляции высоты тона с оригиналом:

| Метрика | Эталон (запись) | XTTS v2 | CosyVoice 3 |
|---|---|---|---|
| Схожесть тембра | 1,000 | 0,678 | **0,908** |
| Корреляция мелодии | 1,000 | 0,039 | **0,419** |
| Высота тона | 106,9 Гц | 110,0 Гц | **106,9 Гц** |
| Время на фразу | — | ~1,4–2 с | ~6–9 с |

Вывод: XTTS меняет тембр, но мелодию рисует заново — фразы звучат ровно.
CosyVoice 3 слышит образец и повторяет его интонацию, поэтому голос звучит как в записи.
Цена — скорость. Разумный режим: XTTS для частых коротких реплик, CosyVoice для голосов,
где важна интонация.

Для CosyVoice нужен точный текст образца: программа собирает кусок записи сама
и расшифровывает его встроенным Whisper, а текст можно поправить вручную.

## Языки сообщений

Программа сама определяет язык сообщения и читает его правильным голосом.

* Определение языка — по алфавиту (кириллица, иероглифы, кана, хангыль, арабский,
  деванагари, тайский) и по частотным словам языка. Смешанные сообщения режутся на
  куски по языкам: в «привет hello» русская часть читается по-русски, английская —
  по-английски.
* XTTS v2 умеет 17 языков: en, es, fr, de, it, pt, pl, tr, ru, nl, cs, ar, zh-cn, hu,
  ko, ja, hi. Остальные читаются ближайшим родственным: украинский и белорусский —
  русским, греческий, иврит, тайский, вьетнамский — английским.
* Китайский и японский требуют пакетов `pypinyin` и `cutlet` (для японского ещё словарь
  `unidic-lite` для MeCab) — `install.bat` ставит их сам.
* Длинные тексты программа режет сама — по границам предложений (европейская
  пунктуация и восточноазиатская 。！？…；): фраза посередине не разрывается, а куски
  укладываются в лимиты модели по каждому языку. Встроенное разбиение XTTS
  отключено: оно требует тяжёлый пакет spacy.
* XTTS на коротких иероглифических фразах иногда не заканчивает фразу и продолжает
  говорить — получается лишний хвост. Такие рендеры программа переспрашивает другим
  sample, а если хвост остался — отрезает его.
* У голосов на CosyVoice 3 язык подбирается сам: CosyVoice 3 — китайско-английская
  модель, поэтому она читает русский, английский и китайский, а корейский и японский
  уходят в XTTS (тембр остаётся тем же голосом). В смешанном сообщении части склеиваются.
* В настройках «Язык сообщений» можно оставить «Авто» (определять по тексту) или
  заставить читать всё на русском или английском.

## Эмоции в сообщениях

Ремарка в скобках или звёздочках не читается словом, а превращается в звук:

```
ну ты даёшь (смех)        *вздыхает* опять понедельник        [кашель] кхм, внимание
```

Подходят круглые и квадратные скобки, звёздочки и угловые скобки; перед словом можно
поставить одно уточнение — `(громкий смех)`, `(тихо вздыхает)`. Незнакомые ремарки
(`(со скидкой)`) читаются как обычный текст.

| Что пишет зритель | Папка в `sounds/` | CosyVoice 3 умеет сам |
|---|---|---|
| смех, смеётся, хохочет, ржу, хаха, лол, laughs | `laugh` | да |
| вздох, вздыхает, sigh | `sigh` | да |
| вдох, выдох, breath | `breath` | да |
| кашель, кашляет, кхм, cough | `cough` | да |
| хм, ммм, задумался, hmm | `hmm` | да |
| цок, цокает, tsk | `tsk` | да |
| чмок, целует, kiss | `smack` | да |
| шипит, шшш, hiss | `hiss` | да |
| плач, плачет, рыдает, cry | `cry` | нет |
| крик, кричит, орёт, scream | `scream` | нет |
| зевок, зевает, yawn | `yawn` | нет |
| ах, ох, в шоке, gasp | `gasp` | нет |

Как звучит эмоция, зависит от движка голоса:

* **CosyVoice 3** смеётся и вздыхает сам, тембром персонажа: ремарка превращается
  во встроенный тег модели (`[laughter]`, `[sigh]`, …). Ничего настраивать не нужно.
* **XTTS и RVC** таких тегов не знают, поэтому в речь вклеивается запись из папки
  `sounds/<эмоция>/` рядом с программой. Папки создаются при первом запуске,
  внутри лежит `ПРОЧТИ.txt`. Положите туда короткие файлы (wav, mp3, ogg; до 6 секунд) —
  если их несколько, каждый раз берётся случайный. У RVC-голоса запись проходит через
  модель вместе с речью и получает тембр персонажа.
* Свой звук для конкретного голоса — вложенная папка с именем голоса:
  `sounds/laugh/Геральт/смех.wav`.
* **Если записи нет — звук эмоции генерирует тот же голос, которым читается сообщение.**
  Программа синтезирует отдельный короткий звук («фх…», «ха-ха-ха…», «сссс…») и вклеивает
  его в речь. Слово («вдох», «смех», «плач») не читается никогда.
* Сгенерированные звуки кэшируются: повторная та же эмоция тем же голосом уже готова.

Подряд идущие одинаковые ремарки звучат один раз, в одном сообщении — не больше четырёх
эмоций. Выключатель — «Настройки» → «Эмоции».

## Голоса персонажей (RVC)

RVC-модель не читает текст сама: программа читает сообщение обычным «базовым» голосом,
а RVC меняет тембр на голос персонажа. Базовый голос стоит брать того же пола, что и персонаж.

**Обучение своей модели прямо из приложения:**

1. Нужен установленный Applio.
2. Вкладка «Голоса» → карточка «Обучить свою RVC-модель из записей».
3. Вписать имя, перетащить записи (5–10 минут чистой речи), выбрать базовый голос,
   нажать «Обучить модель».
4. Прогресс виден в карточке, журнал — в раскрытии «Журнал обучения», отмена — в любой момент.
5. Готовая модель сама добавится в список голосов.

Обучение занимает от 10 минут до пары часов. Пока идёт обучение, чат лучше отключить:
видеокарта занята.

## Настройки

Основные (вкладка «Чат» и «Озвучка»):

| Параметр | Смысл |
|---|---|
| Громкость / скорость | громкость (0–200 %) и темп озвучки |
| Длина очереди | сколько сообщений ждут озвучки |
| Пауза между репликами | анти-спам, в секундах |
| Аудитория | все / только подписчики, VIP и модераторы |
| Читать сообщения из одних цифр | по умолчанию выключено — иначе опрос превращается в кашу |
| Сообщения наград за баллы | по умолчанию не озвучиваются |
| Игнорируемые боты | nightbot, streamelements, moobot, fossabot, streamlabs, wizebot |
| Стоп-лист слов | сообщения с этими словами не читаются |

Файл настроек: `data/settings.json`. Пример с полными ключами — `data/settings.example.json`.

## Интерфейс и дизайн-система

Интерфейс собран вокруг одной дизайн-системы в `app/web/style.css`:

* **Токены** — семантические переменные: поверхности (4 уровня), границы, текст,
  акцент (фиолетовый), статусы (успех / предупреждение / ошибка), шкала отступов
  4–48, радиусы 8–18, размеры шрифта 12–28, два уровня тени, три длительности анимации,
  ширина рабочей колонки (`--shell`: 1320 px, для рабочего пространства «Опроса» — 1560 px).
* **Компоненты** — кнопки (primary / secondary / ghost / danger, состояния hover,
  active, disabled, loading), поля ввода, выпадающие списки, чекбоксы-карточки,
  карточки с заголовком и описанием, бейджи, статусные пилюли, дропзона,
  прогресс-бар, журнал, раскрывающиеся секции, пустое состояние, ряд кнопок
  одинаковой ширины (`.btn-row`), плитки показателей (`.rstats`).
* **Доступность** — видимый фокус с клавиатуры (`focus-visible`), роли и состояния
  у переключателя движка, учёт `prefers-reduced-motion`, подписи полей.

Страница «Опрос» (`poll.html`) должна одинаково выглядеть и как вкладка приложения,
и как отдельный файл, открытый с диска, поэтому внутрь неё встроена копия общих стилей.
После правки `style.css` синхронизируйте копию:

```
python tools/sync_poll_css.py
```

Скрипт обновляет и автономную копию страницы (`twitch-poll.html`), поэтому
она всегда совпадает с `app/web/poll.html`.

Ширина колонки и размеры шрифта заданы токенами, поэтому вёрстка одна и та же
от 640 px до широких мониторов. Проверить её можно служебными скриптами:

```
python tools/audit_layout.py      # переполнения и обрезка на 7 разрешениях
python tools/audit_functional.py   # клики, API, диалоги, автономный файл
python tools/audit_functional2.py  # мьют озвучки и громкость 0-200 %
```

## Структура проекта

```
TwitchTTS/
├── app/
│   ├── main.py             # сервер (Starlette+uvicorn), API, синтез, очереди
│   ├── engine.py           # движок XTTS v2: загрузка модели, слепки голоса, синтез
│   ├── voices.py           # хранилище голосов: нарезка, слепки, движок, транскрипт
│   ├── cosyvoice.py        # мост к процессу CosyVoice 3 (протокол через stdin/stdout)
│   ├── cosyvoice_worker.py # воркер CosyVoice 3 в его окружении + Whisper
│   ├── rvc.py              # мост к Applio (инференс RVC-моделей)
│   ├── rvc_worker.py       # воркер RVC в окружении Applio
│   ├── rvc_train.py        # обучение RVC-модели из записей (обучатель Applio)
│   ├── textproc.py         # чистка текста, разбивка на фразы, пропуск цифр и команд
│   ├── twitch.py           # анонимное чтение чата Twitch
│   └── web/                # index.html, poll.html, voices.html, overlay.html, style.css
├── data/                   # настройки, логи, кэш (в репозиторий не попадает)
├── voices/                 # ваши голоса и модели RVC (в репозиторий не попадает)
├── venv/                   # окружение Python (в репозиторий не попадает)
├── install.bat             # установка окружения
├── start.bat               # запуск программы
├── get_applio.bat          # установка Applio для RVC
├── tools/                  # служебные скрипты: синхронизация стилей, аудит вёрстки
├── twitch-poll.html        # отдельная страница опроса
├── ИНСТРУКЦИЯ.txt          # краткая инструкция для пользователя
└── ОПРОС-ОЗВУЧКА.txt      # подробно про опрос и озвучку объявлений
```

Подробно о модулях и потоках данных — в [ARCHITECTURE.md](ARCHITECTURE.md).

```
git clone <url>

install.bat
start.bat
```

* Сервер: Starlette + uvicorn, порт по умолчанию 8765 (`TTS_PORT` в окружении).
* API: JSON, CORS открыт (страница и OBS могут обращаться с разных источников).
* Синтез выполняется в пуле потоков, воркеры XTTS/RVC/CosyVoice — отдельные процессы,
  общение построчное через stdin/stdout.
* Форматирование: `black`-совместимый стиль, `# -*- coding: utf-8 -*-` в каждом модуле.

## Решение проблем

| Симптом | Причина и что делать |
|---|---|
| `Error opening input stream .../wetext/fsts/.../tagger.fst` | кириллица в пути к модели CosyVoice — перенесите её в латинскую папку |
| `CosyVoice 3 не подключён` | нажмите «Подключить» в карточке CosyVoice 3 и проверьте путь |
| `CUDA out of memory` | выгрузите CosyVoice (модель ленивая) или уменьшите очередь |
| Порт 8765 занят | другой экземпляр уже запущен; задайте `TTS_PORT=8768` |
| Тишина в браузере | нажмите «Включить звук»; звук идёт из вкладки браузера |
| Модель XTTS скачивается заново | удалён кэш в `models/hf` — он лежит рядом с программой, не в `C:\Users` |
| Сообщения не читаются | проверьте «Читать сообщения из одних цифр» и стоп-лист слов |
