# CONTEXT.md — словарь проекта TwitchTTS

Имена вещей, из которых состоит приложение. Модули в `app/` названы по этим
терминам: правила чата живут в `chat_rules.py`, HTTP и настройки — пока в
`main.py` (см. «Разделение `app/main.py`» в ARCHITECTURE.md).

## Сообщение и правила

* **Сообщение** — реплика зрителя в чате Twitch. Приходит из `app/twitch.py`
  как словарь: текст, ник, права, теги IRC.
* **Правило** — решение, что делать с сообщением: прочитать, пропустить,
  выполнить команду или объявить событие.
* **Решение** — результат правил: `Decision` из `app/chat_rules.py`. Ничего
  не выполняет, только описывает.
* **Реестр команд** — таблица «команда → действие» в `app/chat_rules.py`.
  Единственное место, где перечислены все команды чата.
* **Команда** — сообщение, начинающееся с «!». Часть доступна всем
  (`!г`, `!курс`, `!перевод`), часть — только модератору и стримеру
  (`!скип`, `!выделить`, `!закрепить`, `!брб`, `!таймаут`).
* **Событие** — системное сообщение Twitch: рейд, подписка, подарочная
  подписка, битсы. Видно только по тегам IRC, фоллов в чате нет.
* **Награда** — сообщение, отправленное за баллы канала. Приходит с тегом
  `custom-reward-id`; по названию определяется через Twitch API.

## Голос и звук

* **Голос** — набор записей или обученная модель RVC. У голоса есть тембр,
  тон, громкость и движок (XTTS или CosyVoice 3).
* **Стиль речи** — интонация: радостно, грустно, зло, шёпотом, спокойно.
  Задаётся ремаркой в начале сообщения или настройкой по умолчанию.
* **Параметры стиля** — скорость, тон, «температура», громкость, срез частот.
  Общие для всех голосов и свои для каждого (`data/style_presets.json`).
* **Эмоция** — звук внутри сообщения: смех, вздох, кашель. Либо своя запись из
  `sounds/`, либо тег CosyVoice, либо вокализация, которую генерирует голос.
* **Очередь озвучки** — что программа должна произнести и в каком порядке.
* **Синтез** — путь от текста к звуковому файлу: чистка, выбор движка,
  XTTS/RVC/CosyVoice, запись в `data/cache`.

## Twitch API

* **Токен Twitch** — OAuth-токен модератора или стримера. Без него не работают
  новые подписчики, награды по названию и таймаут зрителя.
* **Client ID** — идентификатор приложения в консоли разработчика Twitch.

## Интерфейс

* **Панель** — `app/web/index.html`: чат, очередь, настройки.
* **Опрос** — `app/web/poll.html`: голосование и озвучка объявлений.
* **Голоса** — `app/web/voices.html`: свои голоса, движки, обучение RVC.
* **Оверлей** — `app/web/overlay.html`: прозрачный чат для OBS.
* **Плеер** — `app/web/player.html`: отдельная страница со звуком озвучки,
  свой звуковой канал для OBS.
* **BRB-экран** — `app/web/brb.html`: заставка «скоро вернусь» с таймером.

## Проверки

* **Золотой слепок** — `tools/golden_chat.json`: зафиксированные решения чата
  по 47 случаям. `tools/golden_chat.py` снимает слепок, `tools/test_chat_rules.py`
  сверяет его с эталоном. Расхождение означает смену поведения.
