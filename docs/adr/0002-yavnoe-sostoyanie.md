# ADR 0002. Состояние передаётся явно, глобальных переменных нет

Дата: 2026-11-15 · Статус: принято

## Контекст

Изначально HTTP-обработчики и правила чата читали единственную глобальную
переменную `app_state`. С такой связностью модуль нельзя было проверить без
поднятия всего приложения, а правка одного модуля незаметно задевала другой.

## Решение

* `app/api.py` не знает про `main.py`: состояние приходит аргументом
  (`build_routes(state)`), обработчики получают его первым параметром.
* `app/chat_rules.py` — чистая функция: на входе снимок состояния (`Context`),
  на выходе решение (`Decision`). Ни файлов, ни сети, ни очереди.
* Глобальными остаются только константы и кэши без состояния запроса
  (курс валют, перевод).

## Последствия

* Табличные тесты правил и маршрутов работают без сервера.
* Модуль можно заменить или выбросить, не трогая остальные.
* Цена: чуть больше кода в местах сборки — зато видно, кто что держит.
