1. Идея

Локальное монолитное приложение с изолированными компонентами. Не микросервисы: всё живёт в одном процессе, кроме двух ML-воркеров, у которых собственные окружения.

Главный принцип — разделение по швам, а не по файлам: каждый модуль отвечает за одно решение и получает состояние явно. Правило: «исправление одной части не должно ломать другую». Поведение продукта при разбиении не меняется — это проверяется золотыми слепками, а не на глаз.

Ориентир, а не догма: пакеты api/, core/, tts/ из ТЗ не создаются — они добавят пустые модули без выигрыша. Разделение идёт по границам ответственности внутри app/.

6. Производительность и GPU

Baseline (замерено, RTX 5070 12 ГБ)

МетрикаЗначение
Первая фраза (прогрев модели)20.1 с
Обычная фраза (7.8 с звука)7.9 с
RTF (генерация / длительность)≈ 1.0
GPU во время синтеза96 %
VRAM в простое3.9 ГБ
VRAM в пике синтеза8.0 ГБ
Ожидание в очереди на сообщение≈ 2 × длительность

Причина долгого ответа найдена: воркер ждёт конца звучания текущего сообщения и только потом берёт следующее. Ускорение — не в модулях, а в конвейере.

Рычаги (отдельный этап, каждый с замерами)

  • Предгенерация следующего сообщения во время звучания текущего — снимает время прослушивания с критического пути (ожидаемо ×2 по задержке).
  • fp16 для XTTS — быстрее и вдвое легче по VRAM, только после слепого A/B.
  • Пакетный синтез длинных фраз (разбиение на предложения уже есть).
  • Выгрузка RVC/CosyVoice из VRAM, когда они не обучаются.
  • Устранение цикла textproc ↔ emotes и лишних копий аудио.

Правило качества

Приоритет неизменен: качество голоса → функциональность → стабильность → безопасность → ресурсы → скорость → удобство разработки. Точность вычислений, sampling и алгоритмы движков не трогаем без доказательства. Контрольный набор: tools/quality_baseline.py — 8 фиксированных текстов, один голос, манифест с параметрами; «до» и «после» сравниваются вслепую.

7. Безопасность и данные

  • находка twitch_token и twitch_client_id отдаются в /api/state и в SSE-событии settings. CORS разрешает origin null (страница с диска), значит любой открытый локальный HTML может прочитать токен. Нужен ваш выбор: маскировать секрет в ответах (контракт меняется) или оставить.
  • в порядке загрузки ограничены 500 МБ и 40 файлами, путь к wav проверяется на / и \, приватные пути и CORS ограничены localhost.
  • в порядке пользовательские данные (голоса, слепки, записи, настройки) при разбиении не переносятся и не переписываются.

9. Definition of Done

  • Функциональность, API-контракты и настройки совместимы с текущей версией.
  • Нет циклических импортов, глобального состояния и дублирования путей.
  • 13 наборов тестов + 3 золотых слепка зелёные на каждом шаге.
  • Качество голоса подтверждено контрольным набором (до/после).
  • Скорость и VRAM измерены до и после — без ухудшения качества.
  • Документация соответствует коду; на каждое существенное решение — ADR.
